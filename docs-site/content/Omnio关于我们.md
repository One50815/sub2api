## Omnio 是什么

Omnio 是应用与 AI 模型之间的一层连接服务。你可以通过统一的控制台创建 API Key、查看可用模型、管理额度和查询用量，再使用兼容主流协议的接口，把模型能力接入自己的程序、工作流或第三方客户端。

我们不要求用户围绕某一个模型重做全部应用。Omnio 更关注连接本身：尽量减少重复配置，保持调用方式清晰，并让模型选择和后续调整更加从容。

## Omnio 适合谁

### 开发者与独立创作者

需要快速验证想法、编写工具或为个人项目接入 AI 能力，同时希望减少接口适配和日常管理成本。

### 产品团队与技术团队

需要为多个环境或项目分别管理 API Key、额度和调用情况，并希望保留模型选择与切换空间。

### 正在探索 AI 的使用者

希望通过一个清晰入口了解不同模型、完成第一次调用，并逐步把 AI 能力加入真实工作流程。

## 我们重视的服务体验

- **简单**：减少不必要的步骤，让第一次接入和后续维护都更直接。
- **稳定**：持续维护调用链路和平台能力，认真处理影响实际使用的问题。
- **透明**：让用量、余额、政策和可用能力尽可能清晰可查。
- **响应**：通过文档、客服和工单承接反馈，并让问题处理过程能够被持续跟进。

## 清晰的服务边界

Omnio 提供的是模型接入、转发与管理服务，不是模型本身的开发者。模型输出质量、能力边界和可用性可能受到具体模型及相关上游服务影响。我们会在平台能力范围内持续优化连接和使用体验，但不会用模糊承诺替代真实的服务规则。

使用 Omnio 时，请妥善保管 API Key，遵守适用法律法规、[《用户服务协议》](https://omni0.top/docs/user-agreement/)及相关政策。涉及充值、未消费余额和退款处理时，请查看[《数字充值服务政策》](https://omni0.top/docs/recharge-policy/)。
