# Omnio 数字充值服务政策

> 本政策适用于 Omnio 提供的按量付费充值服务。

## 一、定义

1. **按量付费充值服务**：指您通过一次性付费，向账户充入可用于抵扣 API 调用费用的余额，并按实际用量扣减的数字内容或在线功能服务。

2. **充值余额**：指您完成支付后到账、用于按量计费的账户余额，按需扣减、永不过期。

3. **到账 / 生效**：指您完成支付后，对应充值余额在系统中入账并可用。

4. **账户**：指您基于手机号、邮箱或第三方账号注册并登录本服务所使用的唯一身份。

## 二、充值到账与账户

1. 您应确保注册信息真实、准确、完整并及时更新。

2. 充值到账以我们系统记录为准；您完成支付即视为同意我们立即提供数字充值和在线服务。

3. 充值余额仅供账户主体使用；除非产品明确支持成员席位或团队版，您不得转让、出借、出租或共享账户。

4. 如因您的账户共享、不当保管导致的损失，由您自行承担。

## 三、充值方案与价格

1. 我们提供不同充值金额与到账规则，详见官网的 [Omnio 钱包 / 按量付费](https://omni0.top/purchase)页面。

## 十、取消与退款政策

### 10.1 订单取消

如您尚未完成支付，可关闭支付页面或等待订单超时自动取消。

充值订单一经支付成功并到账，不适用订阅式取消；如需退回未消费余额，应按本政策申请退款。

### 10.2 退款原则

按量付费数字充值余额支持退款。您可就账户内尚未消费、可核验的充值余额申请退款。

退款仅针对未消费的充值余额；已消费部分、已实际履行的在线服务部分不予退还。

### 10.3 退款金额的扣除规则

办理退款时，我们将从可退款金额中扣除以下费用：

- **支付手续费**：按本次实际支付金额的 0.6% 计算，该费用由第三方支付通道收取，不予退还。
- **邀请机制额外费用**：因本次充值触发邀请机制、已发放给邀请人的奖励所产生的额外费用。该部分已发放给他人，退款时需相应扣除。

上述两项费用合计最高不超过 100 元。

> **示例**：若 0.6% 支付手续费与本次充值已发放给邀请人的奖励成本合计超过 100 元，按 100 元封顶扣除；剩余可退款金额按原支付路径退回。

### 10.4 与中国大陆“七日无理由退货”的关系

依照现行消费者相关规定，已下载或已开启的数字内容、已履行的在线服务，通常不适用“七日无理由退货”。

您在结账时点击“确认支付”或“立即支付”，即视为同意我们立即开始提供数字充值和在线服务。未消费余额可按本政策申请退款，但已消费部分不适用七日无理由退货。
